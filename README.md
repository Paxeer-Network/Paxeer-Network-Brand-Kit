## Typography

Three-font system. Paxeer Grand Sans anchors the brand. Inter carries the content. JetBrains Mono speaks to builders.

| Role | Font | Usage |
|------|------|-------|
| **Display / Brand** | Paxeer Grand Sans Regular (400) | Headlines ≥28px, covers, hero copy. Single weight; hierarchy comes from size. |
| **UI / Body** | Inter (variable) | All interface text, body copy, labels, product UI. |
| **Code / Data** | JetBrains Mono | Wallet addresses, block numbers, tech metadata, code. |

### Type Scale

| Name | Font | Size / Line Height | CSS |
|------|------|-------------------|-----|
| **Display 1** | Paxeer Grand Sans | 72px / 1.167 | `font-family: 'Paxeer Grand Sans'; font-size: 72px; font-weight: 400; line-height: 1.167;` |
| **Display 2** | Paxeer Grand Sans | 54px / 1.222 | `font-family: 'Paxeer Grand Sans'; font-size: 54px; font-weight: 400; line-height: 1.222;` |
| **Display 3** | Paxeer Grand Sans | 34px / 1.294 | `font-family: 'Paxeer Grand Sans'; font-size: 34px; font-weight: 400; line-height: 1.294;` |
| **Display 4** | Inter Regular | 24px / 1.417 | `font-size: 24px; font-weight: 400; line-height: 1.417;` |
| **Heading 1** | Inter Regular | 54px / 1.222 | `font-size: 54px; font-weight: 400; line-height: 1.222;` |
| **Heading 2** | Inter Regular | 38px / 1.316 | `font-size: 38px; font-weight: 400; line-height: 1.316;` |
| **Heading 3** | Inter Regular | 24px / 1.417 | `font-size: 24px; font-weight: 400; line-height: 1.417;` |
| **Body Large** | Inter Regular | 24px / 1.583 | `font-size: 24px; font-weight: 400; line-height: 1.583;` |
| **Body Default** | Inter Regular | 18px / 1.667 | `font-size: 18px; font-weight: 400; line-height: 1.667;` |
| **Body Small** | Inter Regular | 14px / 1.714 | `font-size: 14px; font-weight: 400; line-height: 1.714;` |
| **Code / Mono** | JetBrains Mono | 14px / 1.5 | `font-family: 'JetBrains Mono', monospace; font-size: 14px; line-height: 1.5;` |

> **Rule.** Below 28px, transition from Paxeer Grand Sans to Inter for readability.

## Motion

One easing curve. Four duration tiers. Every animation guides attention or rewards action.

### Easing

```css
--ease-standard: cubic-bezier(0.4, 0, 0.2, 1);
```

Fast out, slow to settle. Precise.

### Duration Scale

| Token | Duration | Use |
|-------|----------|-----|
| `--duration-instant` | 80ms | Toggle, focus rings |
| `--duration-snappy` | 150ms | Button press, hover |
| `--duration-standard` | 240ms | Panel, modal, page |
| `--duration-deliberate` | 400ms | Hero reveal, brand moment |

```css
:root {
  --ease-standard:      cubic-bezier(0.4, 0, 0.2, 1);
  --duration-instant:   80ms;
  --duration-snappy:    150ms;
  --duration-standard:  240ms;
  --duration-deliberate: 400ms;
}
```
